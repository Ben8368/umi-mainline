# 风险与开放假设

只登记未验证的外部假设；实现妥协见 [TECH_DEBT](TECH_DEBT.md)。每项包含阻断边界、现有证据和关闭要求。

## RISK-001：充电参数与硬件保护尚未验收（P1）

阻断 BQ25970 主动电荷泵快充/充电安全声明。历史 DT 与驱动曾关闭保护和忽略错误；采样电阻真实值、传感器接线与限值仍未核实。离线实现必须失败封闭，不能猜值。关闭要求：板级依据、保护寄存器读回、故障条件和温度/电流受控真机测试；详见 [BATTERY](BATTERY.md)。

## RISK-002：目标内核与真机回归缺失（P1）

历史 6.12/7.2 实测不能代替本轮新镜像验收；CI 不验证设备。关闭要求见 [测试矩阵](test-matrix.md)，特别是屏幕恢复、触摸、Wi-Fi、切根与错误路径。

6.18.59 运行闭包仍未完整验收：ath11k / MHI / PCI_PWRCTRL_PWRSEQ 为模块，`Image.gz dtbs` 不生成或安装这些模块；新树未带入旧树手工 PCIe early-poweron 补丁，须核验上游 PCI_PWRCTRL 的等价时序及固件。屏幕恢复、长期稳定性、切根和异常路径仍须独立取证。

首次黑屏、触控 deferred 与 SPMI 重复注册的[修复及实机证据](archive/reviews/2026-10-29-linux-6.18.59-boot-fixes.md)已归档；单次亮屏、触摸事件与 GPU 初始化不关闭上述剩余风险。软件请求 reboot-to-bootloader 或 poweroff 后回到原 6.12 的现象仍待定位，不能把旧系统启动误算作新镜像或关机通过；停止测试时使用已获授权的 bootloader 关机入口。

## RISK-003：外部机器人端到端未验收（P2）

配置文件、标签与离线回归不等于 CodeRabbit / Jules / Renovate App 已授权本仓库或实际接单。关闭要求：指定仓库 App 范围、审查/接单链接、真实交付、停止/交接与人工审查记录。凭据与额外计费不自动创建，详见 [机器人约定](bot-automation.md)。

## RISK-004：依赖与固件闭包未完整锁定（P2）

系统包、完整内核构建输入和第三方固件分发条件尚不构成完整可重现发布闭包。固定身份及未覆盖项见 [依赖](dependency-locks.md)，不得只凭一次构建声称 bit-for-bit 重现。

## RISK-005：PPS 主充电通路实机未验收（P1）

显式主动实验已获本轮授权，不代表保护配置或真机能力已确认。TCPM/PD PHY 的互操作、连续输入、PMIC health、现有 1.5A 电池预算、USB 调试与休眠需逐项实测。阻断日用安全与 25W/30W 快充声明；BQ25970 仍由 RISK-001 阻断。关闭要求：按 [PPS](PPS.md) 记录镜像哈希、PD 合同/输入实测、拔插与受控错误/温度证据。

有限实机证据见 [设备记录](archive/reviews/2026-10-29-pps-device-flash.md)；启动、节点和 Good 状态不能替代实际 PPS 合同、输入功率与温控验收，风险保持开放。
