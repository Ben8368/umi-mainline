# 风险与开放假设

只登记未验证的外部假设；实现妥协见 [TECH_DEBT](TECH_DEBT.md)。每项包含阻断边界、现有证据和关闭要求。

## RISK-001：充电参数与硬件保护尚未验收（P1）

阻断 BQ25970 主动电荷泵快充/充电安全声明。历史 DT 与驱动曾关闭保护和忽略错误；采样电阻真实值、传感器接线与限值仍未核实。离线实现必须失败封闭，不能猜值。关闭要求：板级依据、保护寄存器读回、故障条件和温度/电流受控真机测试；详见 [BATTERY](BATTERY.md)。

SMB5 普通充电同样未获安全验收：现有 4.4V/1.5A DT 参数来自历史移植，不能当成本机电芯标定。硬件 JEITA/安全定时器/看门狗的实际配置及保护读回仍缺；遗留初始化含关闭 SMB5 watchdog 的写入，不把 health=Good 当作完整保护已开启。Gen4 温度函数直接将 RRADC 原值乘 10，而固定厂商驱动从 SRAM 读取有符号 10-bit/0.25°C 温度，二者不是同一数据源，不能直接替换编码；必须核对 RRADC 格式/有效位并与实温对照。厂商还注明 PM8150B USBIN 电压 ADC 在高压时存在异常读数并使用 MID_CHG 回避；本实现未覆盖该 workaround，不能只凭 sysfs 输入电压验收 PPS。详见 [充电审计](archive/reviews/2026-10-30-charging-audit.md)。

## RISK-002：目标内核与真机回归缺失（P1）

历史 6.12/7.2 实测不能代替本轮新镜像验收；CI 不验证设备。关闭要求见 [测试矩阵](test-matrix.md)，特别是屏幕恢复、触摸、Wi-Fi、切根与错误路径。

6.18.59 运行闭包仍未完整验收：本轮完整内核、三个 DTB 与 1372 个模块的 L2 构建/导出通过，见[充电审计](archive/reviews/2026-10-30-charging-audit.md)；上游 PCI_PWRCTRL 路径核查见[迁移记录](archive/reviews/2026-10-29-source-parity.md)。即便模块包完整，也未安装到真实 rootfs；仍须核验上游电源时序、固件与 ath11k 初始化，不把旧树手工 early-poweron 补丁未经实测直接叠加。屏幕恢复、长期稳定性、切根和异常路径仍须独立取证。

首次黑屏、触控 deferred 与 SPMI 重复注册的[修复及实机证据](archive/reviews/2026-10-29-linux-6.18.59-boot-fixes.md)已归档；单次亮屏、触摸事件与 GPU 初始化不关闭上述剩余风险。首次 `reboot-to-bootloader` 是从原 6.12.94 救援系统执行，当时 6.18 镜像尚未启动，因此不能证明 6.18 上的该行为。另一次是在 6.18.59 救援环境执行 `poweroff -f` 后再次运行原 6.12.94 #10；该软件关机目标异常仍待定位。停止测试时使用已获授权的 bootloader 关机入口。

## RISK-003：外部机器人端到端未验收（P2）

配置文件、标签与离线回归不等于 CodeRabbit / Jules / Renovate App 已授权本仓库或实际接单。关闭要求：指定仓库 App 范围、审查/接单链接、真实交付、停止/交接与人工审查记录。凭据与额外计费不自动创建，详见 [机器人约定](bot-automation.md)。

## RISK-004：依赖与固件闭包未完整锁定（P2）

系统包、完整内核构建输入和第三方固件分发条件尚不构成完整可重现发布闭包。固定身份及未覆盖项见 [依赖](dependency-locks.md)，不得只凭一次构建声称 bit-for-bit 重现。现有 GPU 和内嵌触摸固件虽有[字节清单](../firmware/manifest.json)，但原厂版本、部分引入提交与精确再分发条款仍缺失；这是公开发布前的阻断项，不能用同类文件许可代替。源码 BusyBox 的工具链/libc 也未整体锁定。

## RISK-005：PPS 主充电通路实机未验收（P1）

可选 [SOC 限充策略](CHARGE-LIMIT.md)尚需核验电量计 SOC 准确性、上下限完整循环及 PPS 停充/普通复充交互；轮询和电量误差不保证最大过冲。服务状态和硬件 enable 读回不替代电池端净电流、外部输入与保护证据。

历史显式主动实验曾获授权，不扩大为当前硬件盘点轮的设备操作权限，也不代表保护配置或真机能力已确认。TCPM/PD PHY 的互操作、连续输入、PMIC health、现有 1.5A 电池预算、USB 调试与休眠需逐项实测。阻断日用安全与 25W/30W 快充声明；BQ25970 仍由 RISK-001 阻断。关闭要求：按 [PPS](PPS.md) 记录镜像哈希、PD 合同/输入实测、拔插与受控错误/温度证据。

有限实机证据见 [设备记录](archive/reviews/2026-10-29-pps-device-flash.md)；启动、节点和 Good 状态不能替代实际 PPS 合同、输入功率与温控验收，风险保持开放。

## RISK-006：扩展外设身份、固件与板级接线未验收（P1）

蓝牙 UART/PMU 接线来自固定小米 DTS 和上游 binding，但控制器 ROM、NVM/地址、Wi-Fi 共存与恢复尚无本轮证据；厂商 ASD 供电项和上游 QCA6390 pwrseq 的差别也须本机核对。功放、红外、NFC、马达、modem、传感器、相机与无线充电缺口逐项见 [硬件矩阵](HARDWARE_SUPPORT.md)。旧 plus 的 DSP/视频节点启用不证明从其他设备沿用的保留内存或固件正确，不能用于默认镜像验收。阻断整机可用和这些外设已工作的声明；关闭要求是本机型号/接线/校准依据、匹配固件来源及测试矩阵中的独立 L3 记录，不能用相似芯片 compatible 或猜测电源值替代。

八路板级 ADC 温度通道已按固定本机 DTS 接入，但读数/位置/故障响应尚未做本机对照；没有移入 Android 用户态的 125°C trip 值。硬件通道能编译不关闭热保护风险。AW8697 v3 候选含 probe 自动校准及校准失败后继续注册的路径，未直接启用，需完成错误退出/保护与本机标定验收。
