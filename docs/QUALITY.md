# 质量与验收

| 层级 | 证据 | 不能证明 |
| --- | --- | --- |
| L0 静态 | 语法、文档链接、策略、署名、静态审查 | 内核可编译或硬件可运行 |
| L1 合成 | 隔离构建失败、打包、解析与模拟 API 回归 | I²C 写入实际成功、真实保护有效 |
| L2 编译 | 固定 Linux 树与工具链，C 驱动/DTB 编译结果 | 手机启动、温控、充电、文件系统安全 |
| L3 真机 | 指定设备、面板、内核/镜像哈希与测试记录 | 未测设备变种、长期稳定性 |

CI 的统一门禁是 CI result；必需任务必须 success，缺失、失败、取消和意外跳过都拒绝。具体接线见 [ci](ci.md)，真机矩阵见 [test-matrix](test-matrix.md)。

完成定义：范围明确、错误路径有回归、风险与延期实现登记、来源与许可证保留、真实验证命令及未覆盖项可追踪。开发权限保留不代表发布就绪。CI 与机器人审查不替代维护者审查、供电安全或真机验收。
