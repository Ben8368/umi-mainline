# ADR 0001：移植 DockDSM 治理与工具级署名

- 状态：已接受
- 日期：2026-10-28

## 背景

既有实测文档与新 review 存在状态、风险和构建保证漂移；维护者要求完整移植 DockDSM 文档治理及署名规范。

## 决策

继承唯一 AI 入口、Context/Lessons 路由、单一事实源、固定预算检查、证据分层、风险/技术债、ADR、归档、署名钩子与回归。仅迁移制度，不迁移 DSM/QEMU 能力或外部授权。来源固定 bc77c7e，许可见 [PROVENANCE](../PROVENANCE.md)。

## 后果

保留既有硬件专题与历史，治理检查强制链接/预算/ADR 一致性；本轮严格两次本地 commit，再一次性 PR。后续主题用独立提交与人工合并。
