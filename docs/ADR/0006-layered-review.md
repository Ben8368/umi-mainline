# ADR 0006：按行为风险分层审查与缺陷反例验证

- 状态：已接受
- 日期：2026-10-30

## 背景

CodeRabbit 曾发现 PPS 比较、故障锁存和交付回滚缺陷，但已发布的意见不能衡量漏报率；增量审查摘要也不能证明完整调用链与测试质量已覆盖。仅增加机器人意见数量无法解决独立复核与可观察反例缺失。

## 决策

保留当前 HEAD 的 CI result、CodeRabbit 最终反馈和有效意见处置门禁。在其上增加按行为风险分层的专项复核：高风险改动由开发者以外的合格维护者或只读审查会话追踪调用链，记录具体覆盖范围与证据；不强制新增付费服务或自动派单。分级及反例要求以 [QUALITY](../QUALITY.md#分层审查与反例验证) 为权威源。

对重要缺陷验证测试能拒绝对应旧行为，关注正常前置状态、中间写入、错误恢复与独立预期值。CodeRabbit 提供第二路缺陷线索；建议须逐项核实，不自动采纳、不以 Minor 等级降低安全问题优先级。低风险工作不叠加无差别多轮 AI 审查。

## 后果

高风险 PR 增加一份可追溯专项复核记录；CI 无法自动证明复核者独立性、意见正确性或真机安全，由维护者合并前核验。现有提交/推送/评论授权、单写入者、Jules 禁区与设备操作边界继续有效；没有授权或没有复核记录时保持待核验，不伪造通过。
