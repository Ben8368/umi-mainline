# ADR 0002：CI 证据分层与受控机器人协作

- 状态：部分替代
- 日期：2026-10-28
- 替代决定：[ADR 0004](0004-agent-pr-and-jules-delegation.md)
- 替代范围：Jules 小工作包授权方式改为本仓库维护者给予开发 Agent 的受限常设派单授权；其余 CI、安全、路径与人工合并边界保留。

## 决策

Actions 对 PR 运行治理、署名、策略、离线测试与语法，统一 CI result。CodeQL 作安全补充，CodeRabbit 审查，Jules 只接维护者明确授权的文档/测试/已准入离线工具，Renovate 只提依赖 PR。拒绝自动合并与发布。机器人不碰内核、供电、真实分区、CI/治理权限。

最小权限、固定 action commit、无不可信代码执行的元数据工作流、路径占用和容量门禁必须有模拟回归。服务端 App 授权与 Triage 规则不在仓库配置文件控制范围，分别取证，不能假称启用。禁止从 DockDSM 继承用户常设授权、额度或接单状态。

## 后果

增加离线治理成本，换取可审查的工作包与证据。真机与充电安全仍由维护者独立验收，详见 [机器人约定](../bot-automation.md)。
