# ADR 0005：显式开启 PPS 主充电实验

- 状态：已接受
- 日期：2026-10-29

## 背景与授权

维护者本轮明确要求新建分支移植 PPS，接受主动开启，完成后人工验证实机。此前 ADR 0003 隔离未验收 BQ25970；该电荷泵的板级采样电阻与保护参数仍未核实。

## 决策

允许在工作分支增加 TCPM 与 SMB5 的主动 PPS 主充电通路，默认不请求 PPS，通过人工 sysfs 使能。协议协商由上游 TCPM 处理，使用现有电池电流预算限制输入与 FCC，并校正 PM8150B 寄存器编码；通信/健康/寄存器错误停止并锁存，休眠和拔线取消 PPS 使能。

本决定补充 ADR 0003 的后续主动充电实验要求，不替代其 BQ25970 隔离、参数禁止猜测、救援 root 默认值或调试权限决定。不启用板级保护配置缺失的电荷泵，不从本次授权推定已完成实机验收。具体实现与手工步骤见 [PPS](../PPS.md)，开放假设仍在 RISK_REGISTER。

## 证据与后果

代码、故障注入和目标构建记录见[移植记录](../archive/reviews/2026-10-29-pps-port.md)。默认 5V 固定合同；显式 PPS 目标范围 5–9V、0.5–1.5A，电池端仍受既有 1.5A FCC 限制。不能声明达到原厂 25W/30W 功率或充电安全验收。
