# ADR 0004：Agent 改动经 PR 交付与低风险 Jules 派单授权

- 状态：已接受
- 日期：2026-10-29

## 背景

维护者要求 Agent 开发成果不得直接进入主分支，必须通过 PR；允许开发 Agent 将简单、低风险工作派给 Jules，并提供本账户每日 100 条任务的额度信息。

## 决策

所有 Agent 的开发改动均在工作分支提交，通过 PR 审查进入主分支；不得直接在本地或远端主分支提交、推送或合入。原有默认不提交、不推送、不合并、不发布及当前 HEAD 的 CI / CodeRabbit 门禁继续生效。

开发 Agent 可在已授权任务内，自行派发符合既有路径准入、简单低风险且可独立验收的 Jules 工作包，无需再次逐单询问维护者。派单须保留精确范围、额度核对、独占写入、真实回执与人工验收；Jules 不递归派单。账户额度与具体步骤以[机器人约定](../bot-automation.md)为单一事实源，日额度不扩大在途容量、写权限或付费授权。

本决定部分替代 [ADR 0002](0002-ci-and-bot-boundaries.md) 的 Jules 小工作包授权方式，其他边界保持有效；核心内核、供电、真实磁盘、CI 与治理权限继续禁止自动派单。

## 后果

Agent 负责分支检查、任务拆分、交付审阅和复跑验证，维护者保留最终合并与发布权。常设派单授权不等于任意提交、推送或合并授权，也不证明外部服务已经接单。
