# ADR 0003：隔离未验收快充与显式选择根分区

- 状态：已接受
- 日期：2026-10-29

## 背景

原 DTS 禁用 BQ25970 多项保护、缺少真实采样电阻且 Type-C 回调自动启用快充。原一键镜像还隐式依赖旧 initramfs，默认切根会使只读式测试承诺不成立。

## 决策

默认禁用 BQ25970 节点，拒绝主动 enable；不猜板级值或假设保护已可用。错误逐层上抛、清理 notifier/引用并保持 devm 单一释放。正常充电/电量计保留其原路径，完整供电验收继续登记风险。

initramfs 每次重建并原子发布，默认 root none；已安装 Arch 的用户用 ROOTDEV 或 --root 明确选择。保留维护者要求的 root/SSH/USB 调试权限。以后启用主动快充或更改写盘默认值须独立提案与真机证据。

## 证据与后果

离线实际函数故障注入、构建失败/缺产物与解析边界回归见 [修复记录](../archive/reviews/2026-10-29-reliability-fixes.md)。这些不证明完整内核可编译或实机安全，原默认开机进桌面改为需要显式 root 选择。
