# 产品范围

umi-mainline 是 Xiaomi Mi 10（umi / SM8250）的上游 Linux 适配层：DTS、外置面板/触摸/电源驱动、initramfs、构建打包及调试工具；完整 Linux 树独立提供。

目标是可审查、可重现地推进 Arch Linux ARM / Plasma Mobile 设备支持。当前阶段与能力证据只见 [CONTEXT](../CONTEXT.md)、[测试矩阵](test-matrix.md)及历史专题，不把原作者实测当本轮独立验收。

非目标：Android ROM、所有小米变种兼容、自动安装/刷写、未经验证的快充或日用安全保证。Goodix 变种、90Hz、蜂窝/通话/相机/音频等未获得本轮目标验收。
